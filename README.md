# Responsive Internship Board

A beginner-friendly, accessible internship listing interface for the EdVyro Full Stack Development task.

## Features
- Semantic HTML
- Responsive mobile, tablet and desktop layouts
- Vanilla HTML, CSS and JavaScript; no framework
- Reusable internship card data
- Search by title, skill, domain, mode or location
- Domain filter and clear button
- Empty state and error/retry state
- Explicit form labels
- Keyboard-focusable cards
- Skip link and visible focus indicators
- Results announced with an accessible live region

## Supplied fictional records
The five supplied records are INT-101 through INT-105: Frontend Intern, API Engineering Intern, UI/UX Intern, Data Analyst Intern, and Security Operations Intern.

## Files
- `index.html` — semantic page structure
- `styles.css` — responsive styling
- `app.js` — data, rendering, search and filtering

## Run
No build tools are required. Open `index.html` in a browser or use VS Code Live Server.

## Responsive testing
Test at 360px, 768px and desktop width. Capture screenshots if using the optional portfolio upgrade.

## Submission
Publish this folder as a public GitHub repository and deploy the static site (for example with GitHub Pages). Submit the repository/deployed project link according to the current EdVyro submission field.
